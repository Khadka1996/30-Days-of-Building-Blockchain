# LinkedIn post style — 30 Days of Building Blockchain

One post a day at **5:30 pm Nepal time**, with the day's card image.

## Rules
- First line exactly: **"Day X of building Blockchain 🛠️"**
- Simple words, short sentences, like explaining to a friend. Explain any technical word with an everyday comparison.
- Say what was built, how it works, and one thing learned or one bug caught.
- One real number from the day's run (tests passing, gas used, a bug found).
- 100–180 words. Short paragraphs with blank lines between them. Max 2–3 emoji.
- End with the day's GitHub link and 4–5 hashtags.

## Template

```
Day X of building Blockchain 🛠️

Today I built: <project in plain words>

How it works:
<2–3 simple sentences with an everyday comparison>

What I learned:
<one lesson, or one bug the tests caught and how it was fixed>

<one real number from today>

Tomorrow: <next project>

Code: https://github.com/Khadka1996/30-Days-of-Building-Blockchain/tree/main/day-XX

#Blockchain #Solidity #Web3 #BuildInPublic #<topic>
```
